One short line about office life is the whole entry. `main.py` (Python
stdlib only) writes a single joke to `/output/entry.txt`:

> The office printer only ever jams when I'm already late — turns out it's the most punctual employee we have.

Run it with:

```sh
python3 main.py
```

It reads `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), creates the
output directory if needed, and writes `entry.txt` there. The output
is deterministic: the same joke, byte for byte, on every run.
